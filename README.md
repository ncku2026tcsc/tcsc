# 算字大師 v6.67

## 下載

**[下載安裝程式](https://github.com/tcsc2026/tcsc/releases/latest/download/tcsc_setup.exe)**（約 550MB）

雙擊、按「安裝」就好，不用系統管理員權限。

**下載的同時，先把這五顆鍵記熟，再往下學：**

| 鍵 | 名字 | 什麼時候按 |
|---|---|---|
| **F1** | 算字鍵 | 選錯字就按，整句重算；沒進步就再按，換下一個 |
| **F2** | 退回鍵 | 按過頭，退回上一個（**Shift+F2**＝直接回原句） |
| **F3** | 重算鍵／迭代鍵 | 只要有進步就按：把目前算的結果再丟進去算一遍 |
| **F7** | 學詞鍵 | 人名、專有名詞：反白兩個字以上的詞，按 5 下教它 |
| **F8** | 在再鍵 | 在、再選反了（**Shift+F8** 人稱鍵：他、她、它選錯了） |

忘了切中文打出一串亂碼，一樣按 F1。

教學影片：[成為算字大師必要會的五顆鍵](https://www.youtube.com/watch?v=SyYxbcE-QzQ)

第一次開時，Windows 可能跳「已保護您的電腦」：按「其他資訊」，再按「仍要執行」。我們沒有買程式簽章，程式碼全部公開。

使用時鍵盤可能會卡死。不要緊張，雙擊右下角的算字大師圖示就能恢復。圖示沒看到的話，點工作列右邊的 ^ 找。

系統需求：Windows 10／11（64 位元），不用顯示卡。開著約佔 2～3GB 記憶體。

公司電腦裝不了：[下載免安裝版](https://github.com/tcsc2026/tcsc/releases/latest/download/tcsc_portable.zip)，先解壓縮，再開 `tcsc\tcsc.exe`。

## 怎麼用

**正常打字就好，看到有錯，按 F1。**

1. 用你原本的輸入法照平常打字，不用改任何習慣。
2. 看到選錯字，按 **F1**，它會把這段重新算過。
3. 沒錯就繼續打，不用每句都按。

## 最常被問的三件事

### F1 的範圍到哪裡？

改游標前面、到上一個標點或空白為止的那一段，最多 50 個字。游標後面的字不會動。

| 畫面上（｜是游標） | 會改的範圍 |
|---|---|
| 今天天氣很好，我門一起去公圓散不｜ | 我門一起去公圓散不 |
| 這是第一句。這是第二句｜ | 這是第二句 |
| 我有3個 蘋果｜ | 蘋果 |

所以打完一段就按，不用等整段寫完。標點包含逗號、句號、問號、頓號、引號、括號，換行也算。想改更前面的字：反白那段再按 F1。

### F1 和 F3 差在哪？

按 **F1** 會生成 10 個可能的句子組合，再按 F1 就往第 2、第 3 個選項走。

按 **F3** 則會從你現在的字，再重新生成 10 個可能的句子組合。此後可以繼續按 F1，繼續挑下一個選項。

越接近答案，生出來的選項品質越好，所以**只要有進步，就一律建議按 F3**；沒有變好就再按 F1，換下一個。

例子：打出來是「溢波位評議剝柚起」，按 F1 變成「一波位評一波又起」，變好了但還沒對；按 F3 變成「一波未平一波又起」。

### 改不對怎麼辦？

照順序試：

1. 有進步就按 **F3**，再算一遍。
2. 沒進步就再按 **F1**，換下一個答案。
3. 還是改不對：把詞改對，反白按 5 下 **F7** 教它，下次就選得到。人名、專有名詞、一直選錯的詞都這樣做。
4. 把這句寄給我們：右下角圖示 → 「紀錄與回報」 → 「寄信給作者」，我們會拿來改進。
5. 真的真的不行才這樣做：按 **Shift+F2** 回原句，再用 **Win+/** 自己選字（做法見下面的「自己挑字」）。

## 怎麼打全形符號？

按住 **Ctrl+Alt** 就對了，再按下面這些鍵：

| 按住 Ctrl+Alt 再按 | 打出 |
|---|---|
| **[**　**]** | 「　」 |
| **9**　**0** | （　） |
| **K** 或 **1** | ！ |
| **/** | ？ |
| **'** | 、 |
| **;** | ； |
| **L** | ： |
| **`** | ～ |
| **B**　**N**　**H**　**J** | ←　→　↑　↓ |

逗號、句號用**微軟內建**的 **Ctrl+,**、**Ctrl+.**，這兩個不是算字大師的鍵，所以開著別的輸入法時不一定有。

想自己加符號：右下角圖示按右鍵，「按鍵 → 符號鍵…」。

## 開始使用

1. 裝好會自動打開，右下角出現「算」字圖示、跳出「就緒」就能用，第一次要等幾秒。圖示可能收在工作列的 ^ 裡面。
2. 第一次開會跳出一分鐘教學，跟著按就好。
3. 之後想再試：把「這個城市跑步起來」貼到記事本，游標放在最後，按 **F1**。

## 你可能想問

**裝之前**

- **要換掉輸入法嗎？** 不用。它不是輸入法，微軟新注音、新酷音、華碩輸入法等都照用，打完才按鍵改。主要針對微軟新注音測試，其他輸入法沒有全部測過。
- **要錢嗎？** 免費，程式碼開源。
- **檔案為什麼這麼大？** AI 模型整包放在裡面，這樣才能完全離線。
- **電腦跑得動嗎？** 只用 CPU，不用顯示卡；按下去才算，通常不到一秒。開著會佔 2～3GB 記憶體，記憶體很少的電腦可能吃力。
- **會上傳我打的字嗎？** 不會，全部在你的電腦上算，不用連網。只有你按「檢查更新」時會問 GitHub 最新版號。
- **會記錄我打的字嗎？** 平常打字不會。按 F1 時才讀游標前那句；預設只記改不對的句子，加密存在你的電腦、保留 30 天，可以關掉或清除。
- **防毒軟體擋住了？** 新程式沒有簽章，有些防毒軟體會擋。程式碼公開可以檢查，放行或加入例外就好。
- **公司電腦能裝嗎？** 安裝不用系統管理員權限。還是裝不了就用上面的免安裝版；如果公司鎖住執行檔就沒辦法。
- **Mac、手機可以用嗎？** 目前只有 Windows。

**用的時候**

- **按 F1 跳出別的說明頁？** 算字大師沒開，看右下角有沒有圖示。
- **句子本來就是對的，按 F1 也被改？** F1 一定會換一個字，按 **F2** 就回去了。
- **它說「沒抓到要修的句子」或「已停止寫入」？** 先按 Enter 收掉選字底線，再按 F1。
- **鍵盤怪怪的，按鍵像卡住？** 雙擊右下角的算字大師圖示，會放開卡住的按鍵。
- **改不動、沒反應？** 右下角圖示按右鍵，「改不動的時候」→「重新啟用熱鍵」。
- **F 鍵要拿去打遊戲？** 按 **F10** 暫停熱鍵；F 鍵也可以在「按鍵 → 改鍵…」換掉。
- **怎麼更新？** 下載新的安裝程式直接裝，舊版會自動關閉，詞庫和設定都留著。
- **怎麼移除？** Windows 設定的應用程式清單找到算字大師解除安裝，預設留著你的詞庫。
- **有問題或建議？** 寄信到 tcsc2026report@gmail.com，我們會再修改。

## 已知問題

- **模型不認得的專有名詞**（產品名、術語、人名）：按 F1 會越改越差，要**事先**用 F7 教它。
  反白兩個字以上的詞按 **F7**，一下加一段，**按 5 下就夠**（有破音字會先跳小窗選讀音，段數填 5）。
  單字只在一直選不到時才教，按 1～3 下；單字按太多下，同音的一般字也會被改成它。
  已經改亂了：先 **Shift+F2** 回原句、把詞改對（上面的 Win+/ 或重打），再反白按 5 下 F7。
  學過的詞在 **Shift+F7** 可以調段數、刪掉。

### 自己挑字：Shift+F2＋Win+/

F1 越改越亂、或只想換一兩個字自己挑：

1. 按 **Shift+F2**：整句回到你原本打的樣子。
2. 游標移到要改的字前面，按 **Win+/**（Windows 新注音內建的重新選字）：選字底線會回來，像剛打完還沒按 Enter。
3. 用 ←→ 移到那個字、按 ↓ 叫出選字窗挑，挑完按 Enter。

記事本、Notepad++ 可以；終端機不支援 Win+/。

|---|---|

| F2 | 退回上一個候選；退到底＝原句；再按＝刪掉剛剛那句（先提示、再按才刪） |

| Ctrl+Alt+[ ] 9 0 | 「 」 （ ） |
| Ctrl+Alt+K / ' ; L | ！ ？ 、 ； ：（逗號、句號用微軟內建的 Ctrl+, Ctrl+.） |

| Ctrl+Enter ／ Shift+Enter | 換行不送出 |

### 系統匣選單

- **使用說明**：使用說明、快捷鍵一覽、重看教學、快速移動教學
- **我的用字**：人稱（你／妳、他／她）、字形（什麼／甚麼、台／臺……）、F8 也換的得地
- **詞庫**：查詞、我學的詞、常錯字清單、內建詞庫
- **按鍵**：改鍵、符號鍵、快速移動、統一換行
- **通知與改字窗設定**：改字窗位置、大小、外觀、停留時間、列出其他候選
- **改不動的時候**：放開卡住的按鍵、重新啟用熱鍵、清空剪貼簿、恢復原廠設定
- **紀錄與回報**：匯出給作者、寄信給作者、檢查更新、紀錄開關
- **進階**：抓字方式、寫回方式、終端機、亂碼轉中文的細項

## 隱私

- 所有運算都在你的電腦上完成，**不會把你打的字傳給作者或任何人**。
- 唯一會連網的是檢查更新：開機時向 GitHub 查一次最新版號（一天最多一次），不送任何本機資料。不想連網可以在系統匣關掉「開機時檢查更新」。
- 內建的 AI 推論元件 onnxruntime，官方版預設會透過 Windows 的診斷資料回傳使用統計；本程式一啟動就把它關掉。
- 預設只記「改不對的句子」，**加密**存在 `%APPDATA%\tcsc\logs`，只有你這個 Windows 帳號打得開，保留 30 天；
  系統匣「紀錄與回報」可以關掉、一鍵清除，或匯出給作者（解開成一份文字檔讓你先看過、刪掉不想給的，再自己寄）。
- 學的詞（F5、F7）、設定存在 `%APPDATA%\tcsc`，是一般文字檔，可以自己看、自己改。
- 重灌系統或換電腦後，舊的加密紀錄打不開（學的詞不受影響）。

## 從原始碼建置

需要 Windows、[Anaconda](https://www.anaconda.com/)。

```powershell
conda create -n pkg python=3.11
conda activate pkg
pip install onnxruntime numpy pystray pillow pyperclip pyinstaller
```

把 zip 裡 `tcsc\_internal\models\` 的 5 個檔放進 `models\`。詞庫資料不開源（見 [data/README.md](data/README.md)），
原始碼可以閱讀與修改，但要實際執行需要自備詞庫資料。

```powershell
python -m tcsc.main                                        # 直接執行
powershell -ExecutionPolicy Bypass -File build.ps1         # 打包（產出 dist\tcsc\tcsc.exe）
```
